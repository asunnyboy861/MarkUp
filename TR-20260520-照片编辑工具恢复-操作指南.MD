### 1.4 关键市场洞察：iOS 26的影响

**iOS 26 (2025年9月发布) 带来的变化**：
- Apple在iOS 26中恢复了Markup的Loupe/Magnifier功能（仅限截图编辑场景）
- Photos应用中的Markup仍未完整恢复Loupe
- 新的"Liquid Glass"设计语言改变了UI范式

**我们的应对策略**：
- iOS 26的Loupe仅限截图场景，我们的App覆盖全场景（照片/截图/文档/地图）
- 我们提供远超原生Markup的功能集（模板/批量/智能标注）
- 差异化定位：不仅是"恢复"，更是"进化"

### 3.2 详细用户旅程

```
用户旅程 A: 快速截图标注 (最高频场景, 占60%使用量)
═══════════════════════════════════════════════════════

  截图 → 点击截图缩略图 → 点击"标记" → MarkUp自动打开
    ↓
  工具栏自动展开(记忆上次工具)
    ↓
  ┌─────────────────────────────────────────┐
  │  [🔍放大镜] [⭕圆圈] [➡箭头] [A文字]  │
  │  [✏画笔]   [🔲矩形] [💡高亮] [🔲马赛克]│
  └─────────────────────────────────────────┘
    ↓
  选择工具 → 直接在截图上标注 → 点击✓完成
    ↓
  自动保存到相册 + 可选分享


用户旅程 B: 照片标注 (占25%使用量)
═══════════════════════════════════════════════════════

  打开MarkUp → 照片库瀑布流展示
    ↓
  点击选择照片 → 进入编辑器
    ↓
  底部工具栏 → 选择工具 → 标注
    ↓
  点击"完成" → 保存/分享


用户旅程 C: 从其他App分享标注 (占15%使用量)
═══════════════════════════════════════════════════════

  任意App(照片/Safari/邮件等) → 点击分享按钮
    ↓
  选择"MarkUp" → 自动打开编辑器
    ↓
  标注 → 保存回原App / 分享到其他App
```

### 3.3 极简操作设计原则

| 原则 | 实现方式 | 对比竞品 |
|------|----------|----------|
| **零学习成本** | 首次打开即显示交互引导(3步)，之后不再打扰 | Annotable需要探索才能发现功能 |
| **记忆上次选择** | 自动记忆上次使用的工具/颜色/粗细/透明度 | iOS原生Markup每次重置 |
| **智能工具推荐** | 基于图片类型推荐工具(截图→箭头+文字; 照片→放大镜+高亮) | 所有竞品均为静态工具栏 |
| **一键撤销/重做** | 摇一摇撤销 + 工具栏撤销按钮 | 部分竞品无撤销功能 |
| **即时预览** | 所有调整实时预览，无需确认步骤 | iMark需要确认才能看到效果 |
| **手势优先** | 双指缩放/旋转标注; 长按拖动移动标注; 捏合调整大小 | Snap Markup标注无法移动 |

### 5.3 Magnifier/Loupe 渲染器（最核心功能）

```swift
import CoreImage
import Metal
import MetalPerformanceShaders
import UIKit

class MagnifierRenderer {
    private let ciContext: CIContext
    private let metalDevice: MTLDevice
    private let commandQueue: MTLCommandQueue

    init?() {
        guard let device = MTLCreateSystemDefaultDevice() else { return nil }
        self.metalDevice = device
        guard let queue = device.makeCommandQueue() else { return nil }
        self.commandQueue = queue
        self.ciContext = CIContext(mtlCommandQueue: queue)
    }

    func renderMagnifier(
        sourceImage: CIImage,
        center: CGPoint,
        radius: CGFloat,
        zoomLevel: CGFloat,
        borderWidth: CGFloat,
        borderColor: CGColor,
        showCrosshair: Bool,
        outputSize: CGSize
    ) -> CIImage? {
        let sourceExtent = sourceImage.extent

        let cropSize = CGSize(
            width: (radius * 2) / zoomLevel,
            height: (radius * 2) / zoomLevel
        )

        let cropOrigin = CGPoint(
            x: center.x - cropSize.width / 2,
            y: sourceExtent.height - center.y - cropSize.height / 2
        )

        let cropRect = CGRect(origin: cropOrigin, size: cropSize)
            .intersection(sourceExtent)

        guard let croppedImage = sourceImage.cropped(to: cropRect) else { return nil }

        let scaleX = (radius * 2) / croppedImage.extent.width
        let scaleY = (radius * 2) / croppedImage.extent.height
        let scaledImage = croppedImage.transformed(
            by: CGAffineTransform(scaleX: scaleX, y: scaleY)
        )

        guard let circularMask = createCircularMask(
            size: CGSize(width: radius * 2, height: radius * 2)
        ) else { return nil }

        let maskedImage = scaledImage.applyingFilter(
            "CIBlendWithMask",
            parameters: [
                kCIInputMaskImageKey: circularMask,
                kCIInputBackgroundImageKey: CIImage.empty()
            ]
        )

        let positionedImage = maskedImage.transformed(
            by: CGAffineTransform(
                translationX: center.x - radius,
                y: sourceExtent.height - center.y - radius
            )
        )

        return positionedImage
    }

    private func createCircularMask(size: CGSize) -> CIImage? {
        let renderer = UIGraphicsImageRenderer(size: size)
        let image = renderer.image { context in
            let rect = CGRect(origin: .zero, size: size)
            UIColor.black.setFill()
            context.fill(rect)
            UIColor.white.setFill()
            context.cgContext.fillEllipse(in: rect.insetBy(dx: 2, dy: 2))
        }
        return CIImage(image: image)
    }

    func renderMagnifierBorder(
        center: CGPoint,
        radius: CGFloat,
        borderWidth: CGFloat,
        borderColor: CGColor,
        showCrosshair: Bool
    ) -> CAShapeLayer {
        let path = UIBezierPath(
            arcCenter: .zero,
            radius: radius,
            startAngle: 0,
            endAngle: .pi * 2,
            clockwise: true
        )

        let borderLayer = CAShapeLayer()
        borderLayer.path = path.cgPath
        borderLayer.strokeColor = borderColor
        borderLayer.fillColor = UIColor.clear.cgColor
        borderLayer.lineWidth = borderWidth
        borderLayer.position = center

        if showCrosshair {
            let crosshairPath = UIBezierPath()
            crosshairPath.move(to: CGPoint(x: -8, y: 0))
            crosshairPath.addLine(to: CGPoint(x: 8, y: 0))
            crosshairPath.move(to: CGPoint(x: 0, y: -8))
            crosshairPath.addLine(to: CGPoint(x: 0, y: 8))

            let crosshairLayer = CAShapeLayer()
            crosshairLayer.path = crosshairPath.cgPath
            crosshairLayer.strokeColor = borderColor
            crosshairLayer.lineWidth = 1.5
            crosshairLayer.position = center
            borderLayer.addSublayer(crosshairLayer)
        }

        return borderLayer
    }
}
```

### 5.6 导出服务

```swift
import UIKit
import Photos
import CoreImage

class ExportService {
    private let renderer = MagnifierRenderer()

    func exportImage(
        sourceImage: UIImage,
        annotations: [Annotation],
        format: ExportFormat = .png,
        quality: CGFloat = 1.0
    ) -> UIImage? {
        let ciImage = CIImage(image: sourceImage)
        guard let ciImage = ciImage else { return nil }

        var compositedImage = ciImage

        let sortedAnnotations = annotations.sorted { $0.zIndex < $1.zIndex }

        for annotation in sortedAnnotations {
            switch annotation.type {
            case .magnifier:
                if let magnified = renderer?.renderMagnifier(
                    sourceImage: compositedImage,
                    center: annotation.position,
                    radius: annotation.size.width / 2,
                    zoomLevel: annotation.magnifierZoom ?? 2.0,
                    borderWidth: annotation.magnifierBorderWidth ?? 3.0,
                    borderColor: annotation.strokeColor.color.cgColor ?? UIColor.black.cgColor,
                    showCrosshair: annotation.magnifierShowCrosshair ?? true,
                    outputSize: sourceImage.size
                ) {
                    compositedImage = magnified.composited(over: compositedImage)
                }

            case .mosaic:
                if let mosaicImage = applyMosaic(
                    to: compositedImage,
                    rect: CGRect(origin: annotation.position, size: annotation.size),
                    pixelSize: annotation.mosaicPixelSize ?? 10,
                    style: annotation.mosaicStyle ?? .pixelate
                ) {
                    compositedImage = mosaicImage
                }

            case .highlight:
                if let highlighted = applyHighlight(
                    to: compositedImage,
                    rect: CGRect(origin: annotation.position, size: annotation.size),
                    color: annotation.strokeColor.color,
                    opacity: annotation.opacity
                ) {
                    compositedImage = highlighted
                }

            default:
                break
            }
        }

        let context = CIContext()
        guard let cgImage = context.createCGImage(
            compositedImage,
            from: compositedImage.extent
        ) else { return nil }

        return UIImage(cgImage: cgImage)
    }

    private func applyMosaic(
        to image: CIImage,
        rect: CGRect,
        pixelSize: Int,
        style: MosaicStyle
    ) -> CIImage? {
        let scaleX = image.extent.width / rect.width
        let scaleY = image.extent.height / rect.height

        let smallWidth = Int(rect.width / CGFloat(pixelSize))
        let smallHeight = Int(rect.height / CGFloat(pixelSize))

        guard smallWidth > 0, smallHeight > 0 else { return nil }

        let downscaled = image.transformed(
            by: CGAffineTransform(scaleX: 1.0 / scaleX, y: 1.0 / scaleY)
        ).cropped(to: CGRect(
            x: rect.origin.x / scaleX,
            y: image.extent.height / scaleY - rect.origin.y / scaleY - rect.height / scaleY,
            width: CGFloat(smallWidth),
            height: CGFloat(smallHeight)
        ))

        let upscaled = downscaled.transformed(
            by: CGAffineTransform(scaleX: scaleX, y: scaleY)
        )

        return upscaled.composited(over: image)
    }

    private func applyHighlight(
        to image: CIImage,
        rect: CGRect,
        color: Color,
        opacity: CGFloat
    ) -> CIImage? {
        let highlightColor = CIColor(
            red: CIColor(color: UIColor(color)).red,
            green: CIColor(color: UIColor(color)).green,
            blue: CIColor(color: UIColor(color)).blue,
            alpha: opacity
        )

        let highlightImage = CIImage(color: highlightColor)
            .cropped(to: rect)

        return highlightImage.composited(over: image)
    }
}

enum ExportFormat {
    case png
    case jpeg
    case pdf
}
```

### 7.3 价格策略深度分析

#### 为什么不用订阅制？

| 因素 | 分析 |
|------|------|
| 用户心理 | 2024-2025年"订阅疲劳"达到顶峰，用户对工具类App订阅极度反感 |
| 竞品对比 | Annotable $9.99一次性 vs 假设我们$2.99/月 → 2个月回本但用户流失 |
| 功能性质 | 纯本地工具，无持续API成本，订阅制缺乏合理性支撑 |
| App Store趋势 | Apple 2025年算法更新更倾向推荐一次性购买的工具类App |
| 获客成本 | 一次性买断的转化率比订阅高3-5倍（用户心理门槛低） |

#### 为什么免费版包含Magnifier？

| 因素 | 分析 |
|------|------|

| 转化漏斗 | 用Magnifier进来 → 发现其他工具更好用 → 付费解锁 |
| 竞品壁垒 | Annotable的Loupe要$1.99单独买，我们免费提供 |
